### 2. Project Description

Japan Dine is a restaurant discovery and reservation website designed to help users explore Japanese restaurants, find suitable dining options, and make reservations.

The website provides restaurant information, recommendation features, user registration, reservation forms, and a bill calculator. It aims to provide a simple and user-friendly experience for people interested in Japanese food.

### 3. Website Pages

The website consists of six HTML pages:

- **index.html** – Homepage introducing Japan Dine and its services.
- **restaurants.html** – Displays available Japanese restaurants and their information.
- **recommend.html** – Allows users to find restaurant recommendations.
- **register.html** – Provides a registration form for new users.
- **reservation.html** – Allows users to enter reservation details and select payment options.
- **bill.html** – Calculates the reservation bill and displays the payment information.

### 4. Main Features

- User registration with input validation.
- Restaurant browsing and recommendation functionality.
- Reservation form with validation for user inputs.
- Automatic deposit calculation based on the selected restaurant.
- Different payment options, including credit card and voucher.
- Transfer of reservation information between pages using URL parameters.
- Bill calculation based on reservation details.
- Error messages displayed through a common error modal.
- Responsive layout for different screen sizes.

### 5. Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Website styling, layout, and responsive design.
- **JavaScript** – Form validation, interactive features, calculations, and page-to-page data transfer.

### 6. How to Run the Website

1. Extract the submitted ZIP file.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation menu.

No additional software installation is required.
